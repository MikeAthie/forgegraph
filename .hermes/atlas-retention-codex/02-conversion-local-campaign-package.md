## Goal
Create deterministic Atlas `Conversión Local IA` campaign package artifacts that turn an audit into an executable low-cost acquisition campaign.

## Scope
- Campaign brief.
- Offer sheet.
- Funnel map.
- WhatsApp/outreach scripts and follow-ups.
- Launch readiness scorecard.
- Spanish markdown package.

## Out of scope
- LLM calls.
- Database models.
- Provider sends.
- UI.

## Success criteria
- Legacy B2B glassware sample produces a specific segment/offer/CTA and readiness gates.
- No meaningful-spend campaign can be marked ready if offer/attribution/follow-up are weak.
