# Legacy — Account Brief / Context Pack

**Cliente:** Legacy  
**Categoría:** lentes de sol / glasswear de lujo accesible  
**Mercado primario:** Ciudad de México  
**Campaña:** Optical Noir  
**Estado del trabajo:** entrega inicial para revisión de estrategia, contenido y activos de publicación.

---

## 1. Rol de marca

Legacy vende presencia antes que producto. La marca debe sentirse como un archivo editorial nocturno de CDMX: negro profundo, marfil, cobre, producto importado, encuadres limpios y un tono que no grita lujo; lo sugiere.

**Frase guía:** _La noche empieza antes de salir._

## 2. Cliente objetivo

| Segmento | Motivación | Mensaje que debe recibir |
|---|---|---|
| Comprador de estilo CDMX | Quiere una pieza distintiva sin verse producido de más | “El modelo correcto se nota antes de hablar.” |
| Regalo premium accesible | Busca algo con presencia, precio claro y entrega sencilla | “Un detalle elevado, fácil de elegir y coordinar.” |
| Perfil de salida / vida nocturna | Compra para complementar outfit y actitud | “Presencia medida para entrar sin explicar demasiado.” |

## 3. Territorio creativo

- **Nombre de plataforma:** Optical Noir.
- **Sensación:** noche privada, archivo editorial, producto protagonista, silencio visual.
- **Paleta:** negro, marfil, hueso, cobre, verde lente.
- **Composición:** fondos oscuros, mucho aire, producto con contraste alto, tipografía sobria.
- **Copy:** español primero; frases cortas, seguras, sin hype ni promesas exageradas.

## 5. Reglas de marca para publicación

1. No usar lenguaje de escasez si la disponibilidad no fue confirmada el mismo día.
2. No prometer entrega inmediata sin confirmación operativa.
3. Mantener precios públicos cuando estén en sitio/catalogo; no exponer costos, márgenes o inventario exacto.
4. Toda publicación debe tener CTA conversacional: elegir, apartar, consultar, explorar.
5. WhatsApp/DM debe operar como asesoría de estilo, no como push de venta agresiva.

## 6. Criterio de calidad para esta primera entrega

El paquete está listo para revisión si una persona externa puede entender en menos de 10 minutos:

- qué campaña se propone,
- qué piezas se publican,
- qué copy acompaña cada pieza,
- qué activos visuales existen,
- y qué falta aprobar antes de publicación real.
