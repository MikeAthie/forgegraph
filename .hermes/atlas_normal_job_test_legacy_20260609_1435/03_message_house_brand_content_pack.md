# Legacy — Message House / Brand-Content Pack

## Voz de marca

**Directa. No ansiosa. Visual. Española primero.**

Legacy debe sonar como alguien con criterio, no como una tienda persiguiendo clicks.

### Sí

- “Presencia inmediata.”
- “Consulta color y disponibilidad.”
- “El modelo correcto se nota antes de hablar.”
- “Entrar al universo Legacy no tiene que esperar.”

### No

- “Últimas piezas!!!”
- “Compra ya antes de que se acaben.”
- “Los mejores lentes de México.”
- “Oferta imperdible.”

## Mensaje principal

> Lentes importados con estética editorial, presencia medida y coordinación directa desde CDMX.

## Caption system

Cada caption debe tener:

1. Frase editorial de apertura.
2. Una línea de producto/beneficio.
3. Un CTA conversacional.
4. Hashtags limitados y específicos.

### Caption master examples

**Brand launch**  
La noche empieza antes de salir. Legacy reúne siluetas importadas, presencia medida y entrega directa en CDMX. Explora modelos desde $590 MXN.  
#LegacyCDMX #LentesDeSol #CDMX #OpticalNoir

**Product spotlight**  
MONROE en negro: una silueta limpia para entrar sin explicar demasiado. Disponible en Legacy.  
#LegacyMonroe #LentesCDMX #LuxurySunglasses

**Buyer guide**  
Guía rápida Legacy: azul para contraste, negro para presencia directa, oro para luz nocturna, crystal para precisión. El modelo correcto se nota antes de hablar.  
#GuiaLegacy #SunglassesMX

## Visual grammar

- Fondo: negro / marfil / hueso.
- Acentos: cobre y verde lente.
- Producto: grande, limpio, con sombra editorial.
- Texto: poco; máximo una frase hero + una línea secundaria.
- Composición: aire suficiente para que se sienta premium.

## Handoff a diseño/publicación

Antes de publicar, revisar:

- precio visible correcto,
- disponibilidad confirmada,
- modelo/imagen correspondiente,
- CTA alineado a canal real,
- y que no haya claims de inventario o entrega no verificados.
