# Legacy — Creative Asset Map

## Asset principles

La campaña debe verse como una serie, no como piezas sueltas. Todos los assets usan el mismo sistema:

- Fondo oscuro o neutro cálido.
- Texto editorial breve.
- Producto como protagonista.
- Acentos marfil/cobre.
- CTA implícito en caption, no saturado en imagen.

## Revisión visual antes de publicar

- Confirmar que cada imagen sea 1080x1080 o formato apto para feed.
- Confirmar legibilidad del texto en móvil.
- Confirmar que el producto no esté cortado de forma accidental.
- Confirmar que precio/modelo/código coincidan con catálogo.
- Reexportar si Instagram comprime o reduce contraste.

## Siguiente mejora creativa recomendada

El paquete ya sirve como primera revisión. Para una versión más premium, haría una segunda pasada de dirección de arte con:

- mejor recorte/máscara de producto,
