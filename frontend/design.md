# Frontend Design

ForgeGraph now uses a business-like operating console instead of a builder-led interface.

## Design Principles

- Clarity over novelty
- State first, actions second
- Warm neutrals and restrained accents over futuristic gradients
- Summaries before raw logs
- Inspector and timeline patterns for explainability

## Shell Pattern

- Left sidebar: domains
- Top bar: organization scope and time range
- Main content: summary-first domain view
- Secondary drill-down: inspector, trace, or execution view
