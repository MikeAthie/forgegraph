# `src/` Translation Ledger

This file is the single source of truth for the `src/` reference dump burn-down.

Current rule set:
- `src/` is local-only and ignored by git.
- `deleted` means the path was removed from the local dump after disposition.
- `reviewed` means the path has a decision, but still remains in `src/` for translation or later pruning.
- `replacement_path` is the best-fit ForgeGraph destination or current equivalent.
- `waiver_reason` explains why a path is intentionally not being translated.

## Burn-down Status

First pass objective:
- keep only runtime-relevant source areas under active evaluation,
- delete obvious TUI, CLI shell, product-shell, and already-covered support trees,
- preserve traceability for future translation work.
