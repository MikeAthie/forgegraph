Legacy Optical Noir Strategy Brief

Legacy Optical Noir Weekend Social Launch

Strategy Research Brief

Client: Legacy Engagement: Weekend social launch package Delivery rule: Client receives packaged HTML, PDF, PNG, and manifest only. No Markdown files are sent to the client.

Strategic Objective

Launch a premium weekend social package for Legacy Optical under the creative territory Optical Noir: polished, cinematic, high-contrast sunglasses visuals designed for fast client review, approval, and weekend distribution.

ForgeGraph owns the run end-to-end, including department routing, asset generation, QA, packaging, WhatsApp delivery, and durable proof of receipt.

Core Direction

Positioning: Legacy Optical should feel refined, modern, and editorial without relying on people, logos, or text inside the imagery.

Creative mood: Noir lighting, reflective surfaces, deep shadows, sharp highlights, luxury retail atmosphere, clean product focus.

Asset principle: Strategy is approved before asset production begins.

Media requirement: Fresh Codex-backed media worker output only. Images must feature sunglasses with:

  • No text
  • No logos
  • No people
  • No visible brand marks
  • No watermarks
  • No reused stock imagery
  • No typography embedded in the image

Department Pipeline

1. Strategy Research

Define campaign purpose, audience, tone, channel requirements, packaging rules, approval path, and delivery constraints before creative production.

Output: This strategy brief and campaign requirements.

2. Brand

Translate Optical Noir into visual and copy direction.

Brand rules:

  • Premium but direct
  • Minimal copy
  • No visual clutter
  • No logo dependency inside generated assets
  • Avoid generic fashion clichés
  • Keep Legacy Optical positioned as refined and confident

3. Channel

Prepare social-ready outputs for weekend posting.

Recommended formats:

  • Square PNG for feed
  • Vertical PNG for stories/reels cover
  • HTML preview page for client review
  • PDF approval deck for offline review

4. CRM

Prepare client-facing delivery language and recipient control.

Delivery channel: WhatsApp only Tone: Brief, concrete, operational

5. Analytics

Define success tracking and evidence requirements.

Track:

  • Package creation timestamp
  • Asset count
  • QA pass/fail
  • ZIP filename
  • Manifest checksum or version ID
  • WhatsApp send timestamp
  • Delivery/read confirmation where available
  • Approval response from Mike

6. QA

Validate every deliverable before packaging.

QA must confirm:

  • No Markdown files in client ZIP
  • ZIP contains only HTML, PDF, PNG, and manifest files
  • Generated sunglasses assets contain no people, text, logos, or watermarks
  • HTML preview loads correctly
  • PDF renders correctly
  • PNG assets open correctly
  • Manifest matches ZIP contents
  • WhatsApp message is addressed to Mike only
  • Durable evidence is captured

7. Client Approval

Send approved ZIP to Mike via WhatsApp with concise delivery note. Capture receipt and response as durable evidence.

Deliverable Package Specification

Client ZIP contents only:

  • index.html
  • Legacy_Optical_Noir_Weekend_Launch.pdf
  • Approved .png social assets
  • manifest.json or manifest.txt

Explicitly excluded:

  • Markdown files
  • Working prompts
  • Internal notes
  • Draft files
  • Source design files
  • Unapproved images
  • Any asset containing text, logos, people, or watermarks

WhatsApp Delivery Copy

Hi Mike, the Legacy Optical Noir weekend social launch package is ready. ZIP includes the HTML preview, PDF, PNG assets, and manifest only. Please review and confirm approval for weekend use.

Evidence And Receipt Requirements

ForgeGraph must retain durable evidence of:

  • Final ZIP contents
  • Manifest
  • QA checklist result
  • WhatsApp recipient: Mike only
  • WhatsApp delivery timestamp
  • Delivery/read receipt where available
  • Mike’s approval or requested changes

Strategy Gate

No creative assets should be produced until this strategy direction is accepted internally and routed to Brand. Asset generation must follow the approved Optical Noir brief and QA restrictions exactly.
