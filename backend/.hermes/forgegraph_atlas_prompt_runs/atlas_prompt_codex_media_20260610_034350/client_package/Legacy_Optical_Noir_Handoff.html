# Strategy Brief: Legacy Optical Noir Weekend Social Launch

## Engagement Context

**Client:** Legacy
**Campaign:** Legacy Optical Noir weekend social launch package
**Stage:** strategy_research
**Run owner:** ForgeGraph
**Intended use:** Internal lineage for downstream HTML/PDF packaging
**Client-facing formats:** HTML, PDF, PNG, manifest only
**Excluded client formats:** Markdown files must not be sent to the client

ForgeGraph will own the run end-to-end across strategy, brand, channel, CRM, analytics, QA, client approval, packaging, WhatsApp delivery, and durable evidence capture.

## Campaign Objective

Launch a polished weekend social package for Legacy’s Optical Noir concept, centered on a premium sunglasses mood: dark, refined, cinematic, fashion-forward, and commerce-ready.

The campaign should feel like a high-end optical drop rather than a generic seasonal promotion. Strategy must lead creative production so that every asset, caption, format, and delivery artifact traces back to a clear positioning decision.

## Core Positioning

**Campaign idea:**
Legacy Optical Noir presents sunglasses as a style-defining weekend essential: sharp, minimal, confident, and elevated.

**Audience perception goal:**
Legacy should feel premium, curated, and visually distinctive, with the sunglasses positioned as part of a complete weekend look rather than a standalone accessory.

**Tone:**
Refined, direct, modern, understated.

**Avoid:**
Overly loud sale language, crowded layouts, lifestyle imagery with people, logo-heavy compositions, text baked into images, generic luxury clichés, or assets that feel like stock advertising.

## Creative Direction

### Visual World

The asset set should use fresh Codex-backed media worker generation with the following constraints:

- No text in images
- No logos in images
- No people in images
- Sunglasses must be the clear subject
- Premium noir styling
- Suitable for social launch use
- Clean enough for overlays, cropping, and HTML/PDF packaging

Recommended visual motifs:

- Black acetate sunglasses on reflective stone or glass
- Deep charcoal, smoke, and polished metal surfaces
- Controlled highlights and cinematic shadows
- Minimal props, if any
- Close-up product detail shots
- Editorial still-life compositions
- Weekend evening mood without showing people

### Asset Use Cases

Create image assets suitable for:

- Instagram feed
- Instagram story
- WhatsApp preview
- Client approval deck
- HTML/PDF package
- PNG export set

Assets should remain clean and flexible so downstream Brand and Channel departments can add approved copy in layout rather than embedding text directly in the generated media.

## Department Pipeline

### 1. Strategy Research

Own the campaign foundation before any creative asset production begins.

Outputs:

- Campaign objective
- Audience and positioning notes
- Creative direction
- Asset requirements
- Channel assumptions
- QA requirements
- Delivery constraints

### 2. Brand

Translate strategy into a visual and verbal system.

Responsibilities:

- Confirm Optical Noir tone
- Define copy hierarchy
- Prepare social-safe message variants
- Ensure no generated image includes text, logos, or people
- Maintain Legacy’s premium feel

### 3. Channel

Adapt the campaign for weekend social deployment.

Responsibilities:

- Define placement-specific outputs
- Prepare feed/story/WhatsApp-ready versions
- Keep WhatsApp delivery brief and concrete
- Ensure client package supports review without Markdown files

### 4. CRM

Prepare client-facing communication and delivery routing.

Responsibilities:

- Route delivery to Mike only via WhatsApp
- Keep message short, specific, and action-oriented
- Do not include unnecessary internal process details
- Confirm no Markdown files are attached or referenced as client deliverables

### 5. Analytics

Define lightweight tracking and evidence needs.

Responsibilities:

- Confirm final file manifest
- Record asset counts and export formats
- Preserve run metadata
- Capture delivery timestamp and recipient
- Store approval and receipt evidence durably

### 6. QA

Validate the full package before client delivery.

Required checks:

- No Markdown files in client ZIP
- ZIP contains only HTML, PDF, PNG, and manifest files
- All image assets contain no text, no logos, and no people
- Assets align with Optical Noir direction
- Links, filenames, and previews work
- WhatsApp copy is brief and concrete
- Recipient is Mike only
- Evidence capture is complete

### 7. Client Approval

Deliver final package to Mike only via WhatsApp and capture durable receipt.

Responsibilities:

- Send client ZIP only after QA pass
- Confirm package contents
- Send concise WhatsApp message
- Capture delivery proof
- Store receipt/evidence in run lineage

## Required Client ZIP Contents

The final client ZIP must include only:

- HTML
- PDF
- PNG
- Manifest

The ZIP must not include:

- Markdown files
- Working drafts
- Raw prompts
- Internal strategy notes
- Source markdown
- Unapproved alternates
- Any files outside the approved format list

## Media Worker Requirements

ForgeGraph must use a Codex-backed media worker to create fresh sunglasses assets specifically for this run.

Generation constraints:

- No text
- No logos
- No people
- Sunglasses as primary subject
- Noir premium style
- Weekend launch suitability
- Clean composition for social cropping

QA must inspect generated assets before inclusion.

## WhatsApp Delivery Guidance

Recipient: **Mike only**

Message should be brief and concrete. Recommended format:

> Mike, the Legacy Optical Noir weekend social launch package is ready. The ZIP includes the approved HTML, PDF, PNG assets, and manifest only. Please review and confirm approval when ready.

Do not mention Markdown, internal departments, prompts, or operational details in the WhatsApp message unless specifically requested by Mike.

## Evidence And Receipt Requirements

The run must preserve durable evidence of:

- Strategy completion
- Asset generation constraints
- QA pass
- Final ZIP contents
- Delivery recipient
- Delivery timestamp
- WhatsApp message content
- Receipt or confirmation from Mike
- Client approval status

Evidence should be stored as internal lineage and must support later audit of what was created, approved, sent, and received.

## Success Criteria

The strategy_research stage is complete when:

- Campaign positioning is defined
- Department pipeline is clear
- Asset constraints are documented
- Client ZIP rules are explicit
- WhatsApp recipient and message guidance are confirmed
- QA and evidence requirements are established
- Downstream departments can proceed without needing additional strategic interpretation

## Strategic Decision

Proceed with an Optical Noir package built around premium, people-free sunglasses still-life imagery, strategy-led copy and layout, strict client packaging controls, WhatsApp delivery to Mike only, and durable evidence capture for the complete ForgeGraph-owned run.
