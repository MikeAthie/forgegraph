# Strategy Brief: Legacy Optical Noir Weekend Social Launch

## Engagement Summary

Legacy will launch a weekend social campaign for the **Optical Noir** concept: a premium, cinematic sunglasses-focused creative package designed for fast deployment across social channels.

ForgeGraph owns the full run end-to-end, from strategy through packaged delivery. The work must proceed through the agency department pipeline before any final assets are packaged or sent.

This brief is for internal lineage and packaging source only. **No Markdown files are to be delivered to the client.**

## Campaign Objective

Create a polished weekend-ready social launch package for Legacy that positions Optical Noir as sharp, refined, modern, and visually distinctive.

The campaign should feel premium and direct, with strong visual emphasis on sunglasses, light, shadow, reflection, and contrast. The creative should be suitable for fast social publishing without requiring additional client-side editing.

## Required Department Pipeline

The run must move through the following departments in order:

1. **Strategy**
- Define campaign angle, audience, tone, content structure, delivery rules, and asset requirements.
- Confirm that strategy precedes all asset production.

2. **Brand**
- Translate the Optical Noir direction into visual and copy standards.
- Maintain a premium sunglasses-forward aesthetic.
- Avoid logo dependency and avoid any invented brand marks.

3. **Channel**
- Prepare social-ready concepts and formats for weekend launch usage.
- Ensure assets are clear for Instagram, Facebook, Stories/Reels covers, and general promotional placement.

4. **CRM**
- Prepare concise client-facing delivery language.
- Ensure WhatsApp communication is brief, concrete, and sent only to Mike.

5. **Analytics**
- Define tracking-ready campaign metadata and performance assumptions.
- Include naming, asset manifest logic, and durable evidence expectations.

6. **QA**
- Verify all deliverables meet constraints:
- No Markdown sent to client.
- No people in generated sunglasses assets.
- No text embedded in generated media.
- No logos in generated media.
- HTML/PDF/PNG/manifest only in client ZIP.
- WhatsApp delivery to Mike only.

7. **Client Approval**
- Package approved materials into a client-ready ZIP.
- Deliver only approved formats.
- Preserve receipt and evidence of delivery.

## Creative Direction

### Campaign Theme

**Legacy Optical Noir**

The creative system should evoke:
- Premium eyewear
- Cinematic black-and-light contrast
- Night launch energy
- Refined retail polish
- Minimal, confident messaging
- Product-first composition

### Visual Style

Generated media should feature sunglasses only, without people, logos, or text.

Preferred visual treatments:
- Studio product photography style
- Dark reflective surfaces
- Controlled highlights
- Noir-inspired shadows
- Glossy lenses and frames
- Premium editorial lighting
- Clean negative space for later layout use

Avoid:
- Faces, models, hands, or bodies
- Embedded captions or typography
- Brand names, logos, monograms, labels, or watermarks
- Overly futuristic or gimmicky styling
- Busy retail clutter

## Media Worker Requirement

A Codex-backed media worker must be used to generate fresh sunglasses assets.

Asset requirements:
- Freshly generated for this run
- No text
- No logo
- No people
- Sunglasses must be the primary subject
- Suitable for HTML/PDF/PNG campaign packaging
- Usable across social placements

Recommended generated asset set:
- Hero sunglasses image
- Square social post image
- Vertical story image
- Detail/macro lens reflection image
- Dark product arrangement image

## Messaging Strategy

The copy should be concise, premium, and weekend-focused.

Tone:
- Confident
- Minimal
- Retail-ready
- Elegant
- Direct

Suggested message angles:
- Weekend launch
- Limited-time social spotlight
- Sharp seasonal style
- Premium eyewear presentation
- Noir-inspired visual identity

Avoid exaggerated claims, unsupported discounts, or implying product availability details unless confirmed by Legacy.

## Client Deliverable Package

The final client ZIP must contain only:

- HTML
- PDF
- PNG
- Manifest

Do not include:
- Markdown files
- Working files
- Prompt logs
- Source notes
- Internal QA notes
- Unapproved drafts
- Raw generation metadata unless represented appropriately in the manifest

The manifest should document:
- File names
- File types
- Purpose of each file
- Creation timestamp
- QA status
- Delivery target
- Receipt/evidence reference

## WhatsApp Delivery Rule

Delivery must be sent to **Mike only**.

The WhatsApp message should be brief and concrete. It should not include long explanations, internal process details, or Markdown attachments.

Recommended WhatsApp copy:

> Mike, the Legacy Optical Noir weekend social launch package is ready. ZIP includes the approved HTML, PDF, PNG assets, and manifest only. No Markdown files are included.

## Receipt And Evidence Requirements

ForgeGraph must preserve durable evidence for the run, including:

- Department pipeline completion record
- Asset generation confirmation
- QA confirmation
- Final ZIP contents manifest
- Delivery timestamp
- WhatsApp recipient confirmation showing Mike only
- Receipt or delivery evidence reference

Evidence should be retained internally and not exposed to the client unless requested.

## Acceptance Criteria

The run is complete only when:

- Strategy is completed before asset creation.
- Brand, Channel, CRM, Analytics, QA, and Client Approval stages are recorded.
- Fresh no-text, no-logo, no-people sunglasses media assets are created.
- Client ZIP contains only HTML, PDF, PNG, and manifest files.
- No Markdown files are sent to the client.
- WhatsApp delivery is sent to Mike only.
- Delivery message is brief and concrete.
- Durable receipt and evidence are preserved.
