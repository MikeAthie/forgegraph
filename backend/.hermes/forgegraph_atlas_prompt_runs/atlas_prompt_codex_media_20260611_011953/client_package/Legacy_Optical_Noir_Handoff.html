Legacy Optical Noir Strategy Brief

# Strategy Brief: Legacy Optical Noir Weekend Social Launch

## Run Context

**Client:** Legacy
**Campaign:** Legacy Optical Noir
**Engagement:** Weekend marketing sprint
**Stage:** strategy_research
**Department:** Strategy Research
**Agency System:** Atlas, owned end-to-end by ForgeGraph

## Strategic Mandate

ForgeGraph will own the complete Atlas run from strategy through delivery. This sprint must begin with strategic alignment before any visual assets are produced. The final client package must be polished, QA-cleared, and delivered as a ZIP containing only approved client formats: HTML, PDF, PNG, and manifest files.

No Markdown files are to be sent to the client.

## Campaign Objective

Launch a sharp, premium weekend social package for Legacy Optical Noir that positions the collection as cinematic, refined, and immediately desirable. The campaign should feel editorial and high-contrast, with a luxury optical mood built around sunglasses as the hero product.

## Core Direction

**Creative territory:** Optical Noir
**Tone:** Premium, minimal, cinematic, confident
**Visual world:** High-contrast shadows, reflective lenses, black-and-silver styling, moody product surfaces, clean negative space
**Asset rule:** Fresh generated sunglasses visuals only; no text, no logos, no people embedded in the media assets

## Audience Assumption

The package should speak to style-conscious buyers who respond to premium presentation, weekend immediacy, and refined visual identity. The social launch should feel like a limited editorial drop rather than a generic product push.

## Required Pipeline

1. **Strategy Research**
- Define campaign positioning, audience angle, visual guardrails, and delivery constraints.
- Confirm that assets come after strategy approval.

2. **Brand**
- Translate the Optical Noir direction into campaign look, voice, and layout guidance.
- Preserve Legacy’s premium feel without adding unauthorized marks inside generated media.

3. **Channel**
- Prepare weekend-ready social formats and placements.
- Keep copy concise, direct, and campaign-specific.

4. **CRM**
- Prepare any supporting client-facing launch copy or customer-facing messaging blocks needed for HTML/PDF packaging.

5. **Analytics**
- Define success signals: engagement, saves, clicks, inquiries, WhatsApp responses, and launch package delivery confirmation.

6. **QA**
- Verify formats, naming, file contents, visual compliance, no embedded text/logos/people in generated assets, and no Markdown in the client ZIP.

7. **Client Approval**
- Package approved HTML/PDF/PNG/manifest files only.
- Deliver to Mike via WhatsApp only.
- Preserve durable receipt and evidence internally.

## Media Production Requirement

Use the Codex-backed media worker to create fresh sunglasses assets specifically for this run.

Asset constraints:
- No text
- No logos
- No people
- Sunglasses must be the clear subject
- Premium noir styling
- Suitable for social launch layouts
- Export-ready PNGs only for client packaging

## Client Package Requirements

The client ZIP must contain only:

- `.html`
- `.pdf`
- `.png`
- `manifest` file

The ZIP must not contain:
- Markdown files
- Drafts
- Source prompts
- Internal notes
- QA scratch files
- Unapproved images
- Working files

## WhatsApp Delivery Protocol

Recipient: **Mike only**

WhatsApp message must be brief and concrete. Recommended message:

> Mike, the Legacy Optical Noir weekend launch package is ready. The ZIP includes the approved HTML, PDF, PNG assets, and manifest. No Markdown or draft files are included.

## Evidence And Receipt

ForgeGraph must preserve durable internal evidence for the run:

- Final ZIP filename
- Manifest contents
- Delivery timestamp
- Recipient confirmation: Mike
- WhatsApp delivery screenshot or export
- QA approval record
- Asset compliance confirmation
- File checksum or equivalent package integrity record

## Strategy Approval Gate

Do not begin asset generation or packaging until this strategy brief is accepted as the source direction for the Atlas run.
